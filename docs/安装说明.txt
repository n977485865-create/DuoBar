DuoBar 安装说明

系统：macOS 13 或更新版本。安装包同时包含 Apple Silicon 和 Intel 版本。
目前已在 Apple Silicon Mac 验证，Intel 真机尚未验证。

安装 DMG
1. 双击 DuoBar 的 .dmg 文件。
2. 把 DuoBar.app 拖到旁边的 Applications（应用程序）文件夹。
3. 从应用程序文件夹打开 DuoBar，再推出安装磁盘。

安装 ZIP
1. 解压 .zip 文件。
2. 把 DuoBar.app 移到应用程序文件夹后打开。

首次打开
当前版本尚未使用 Developer ID 签名和 Apple 公证。macOS 可能拦截首次打开。
确认文件来自本项目或开发者后，可在尝试打开后进入：
系统设置 → 隐私与安全性 → 安全性 → 仍要打开，然后按系统提示确认。
通常每台 Mac 首次使用时处理一次。受企业管理的设备可能不能自行允许。
无需关闭 Gatekeeper、SIP 或整机安全设置，无需运行终端命令。

使用与首次设置
- DuoBar 在菜单栏显示，没有 Dock 图标。第一次打开会显示设置。
- 按住 Command（⌘）拖动圆形图标到控制中心左侧。macOS 会记住位置；不同屏幕或菜单栏管理工具可能影响排列。
- 单击图标查看状态，点菜单外或按 Esc 收起。
- 四个状态圆点默认从左到右为 VPN、耳机、静音、专注，可排序和隐藏。
- “关闭对应状态栏”会打开系统菜单栏设置，由你选择是否隐藏原生 Wi-Fi、电池等图标。
- 若要登录时自动运行，在 DuoBar 设置里勾选“登录时自动启动”。
- 显示 Wi-Fi 名称需要定位授权；没有权限仍可显示连接和信号。应用不请求地理坐标。
- 专注圆点：在“系统设置 → 专注模式 → 勿扰模式 → 添加过滤条件”选择 DuoBar，将“专注圆点”设为“点亮”后添加，即可随该模式开关。工作、睡眠等需要联动的模式也要各自添加一次；未绑定的模式不会联动。无需通知权限或 Apple 开发者账号。

视觉效果与状态
安装包自带图标、动画和默认配置，不需要额外安装软件、脚本或字体。
亮点数量、电量、Wi-Fi 信号会按你的设备状态变化，不会与开发者电脑的数值完全相同。
Wi-Fi 或四项状态变化时，圆弧与圆点作为完整外圈同步转动，轻微回弹后归位；Wi-Fi 保持正向。
开启省电模式时圆环为系统黄色；未开启省电模式时，接通电源后圆环平滑变绿并轻扫一次，连接期间保持绿色，断开后平滑恢复。系统开启“减少动态效果”时直接更新状态。

更新与卸载
更新：先从 DuoBar 菜单退出，再用新版替换应用程序中的 DuoBar.app；圆点设置会保留。
卸载：先取消登录自动启动并退出，再将应用移到废纸篓。
